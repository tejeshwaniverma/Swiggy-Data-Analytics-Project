Swiggy Sales Dashboard Analysis

An interactive Swiggy Sales Dashboard built using Microsoft Excel to analyze food order data and transform raw data into meaningful business insights.

📊 Key Analysis
-Total Sales: ₹53.01M
-Total Orders: 197.43K
-Average Order Value: ₹268.51
-Average Rating: 4.34
-Rating Count: 5.59M
-Monthly, Daily, and Weekly Sales Trends
-Sales Analysis by Food Type
-State-wise Sales Analysis
-Quarterly Performance Summary
-Top 5 Cities by Sales
🛠️ Tools & Features

Microsoft Excel | Pivot Tables | Pivot Charts | Slicers | Map Charts | Data Visualization | Dashboard Design

This project demonstrates how Excel can be used to analyze sales performance, identify customer and ordering trends, compare food categories, track geographical sales distribution, and create an interactive dashboard for business decision-making.
